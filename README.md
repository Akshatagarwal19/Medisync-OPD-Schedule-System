# Medisync-OPD-Schedule-System

A modern hospital OPD scheduling dashboard built with React and Tailwind CSS featuring timetable-based doctor duty management and operational UI design.

---

## Features

- Modern hospital scheduling dashboard UI
- Timetable-based doctor duty management
- Department-wise scheduling system
- Emergency on-call duty section
- Operational dashboard layout
- Compact enterprise-style timetable grid
- Department filter interface
- Responsive dashboard structure
- Realistic hospital scheduling workflow design

---

## Tech Stack

- React
- Vite
- Tailwind CSS
- Lucide React
